My first dev blog

## Projects

- **[Banker Cold Emailer](https://yshooo.github.io/cold-email/)**: load a list of bankers, write one email template with placeholders (`{{first_name}}`, `{{firm}}`, `{{group|your group}}`, optional `[[...]]` sentences), review every personalized email, then send them through Gmail. Sending is either one click per email or fully automatic with a generated Google Apps Script that sends (or drafts) a batch from your own Gmail every weekday morning. Everything stays in your browser.

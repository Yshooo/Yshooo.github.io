Automatic sending with Gmail

This page can't send email on its own (it runs entirely in your browser), so it generates a Google Apps Script that sends from your own Gmail. Free, no API keys, and nothing leaves your Google account.



    
How to run it (about 3 minutes)

    
    
      
  1. Go to script.google.com while signed in to the Gmail you want to send from, and create a new project.
    2. 
      
  2. Delete the starter code, paste the generated script, and click Save.
    3. 
      
  3. Pick sendTestToMyself in the function dropdown and click Run. Approve the Gmail permission prompt (choose Advanced → Go to project if Google warns it's unverified; it's your own script). Check your inbox.
    4. 
      
  4. When it looks right, run sendNextBatch to send (or draft) the next batch now, or run scheduleDailyBatches to send one batch every weekday morning at your chosen hour until the list is done.
    5. 
      
  5. Run showStatus anytime to see what's been sent. stopSchedule cancels the daily runs.
    6. 
    

    
Gmail limits scripts to about 100 recipients/day on free accounts (1,500 on Workspace). Sending 10–20 a day spread out
      also looks a lot less like spam to bank mail filters. After generating, mark emails as "sent" in step 4 so you can track replies and follow-ups.
